# 仙之巅

**破境延寿，自成一道。** 一款原创中文修仙文字养成游戏。从十六岁入山，到飞升仙界、登临仙帝，灵根、命格、道途和每一年的选择，共同写成这一生的行卷。

- 游戏：https://dailypotato.github.io/xian-zhi-dian/
- 仓库：https://github.com/DailyPotato/xian-zhi-dian

当前玩法版本为 **v2.0.0**，存档格式版本为 3。使用原生 HTML / CSS / JavaScript，无构建步骤、第三方运行依赖、后端或 API 密钥。可在 GitHub Pages 或本机运行，存档仅留在玩家浏览器。

## 怎么玩

1. 选择姓名、10 种灵根与 10 条道途；契合搭配能提高修炼和破境收益，各流派拥有专属行动与奇遇。36 项命格随机抽出 8 项，从中选择 2 项，可重新抽取两次。
2. 每年有 **3 格修行安排**和 **2 次天地游历**。先处理想做的交游、拍卖、秘境或对战，再排满三件修行之事、推进一年；不必用完天地游历次数。
3. 静室修炼积累修为，参悟提高悟性，炼体和凝神提高战力，休整恢复气血与心境。修为达到当前门槛、气血与心境均不少于 20 时，可以安排一次闭关破境；每年最多尝试一次，占一格修行。
4. 年末处理一场奇遇。检定显示概率与成败后果；每场都有无资源门槛的退路，但负面事件的退路仍可能损失气血、心境或修为，不能保证无伤或生还。
5. 筑基后可拜入云岚剑宗、丹霞谷或听雨阁，也可终生不入宗门。师承一经选定，本局不再改投。山门差事所得贡献可用于讲经和三个堂口的兑换。
6. 经历 14 个境界。渡劫后晋入真仙、飞升仙界，游戏继续；最终突破至仙帝才完成登巅结局。气血归零或当前境界寿元耗尽，也会结束这一生。

## 灵根与流派

灵根包括金、木、水、火、土、冰、雷、风、阴、阳，每种都有不同的初始属性和行动收益。流派与宗门相互独立，选择流派后仍可拜入任一宗门。

| 流派 | 契合灵根 | 专属修行与侧重 |
| --- | --- | --- |
| 剑修 | 金、风 | 问剑悟意，兼修剑意与体魄 |
| 丹修 | 木、火 | 双炉合丹，药草 ×2、45 灵石炼出聚气丹 ×2 |
| 逍遥 | 水、风 | 乘风行吟，游历养心并赚些盘缠 |
| 体修 | 土、阳 | 熬骨淬身，较高气血消耗换取体魄成长 |
| 阵修 | 土、水 | 推阵结符，灵矿 ×1、30 灵石炼出护身符 ×1 |
| 御兽 | 木、阳 | 万灵共鸣，培养神识并平复心绪 |
| 玄冰 | 冰、水 | 寒潭吐纳，修为、悟性与心境一并成长 |
| 雷修 | 雷、金 | 引雷淬脉，较高气血和心境消耗换取进境 |
| 魂修 | 阴、冰 | 照魂守灯，着重神识，需注意心境恢复 |
| 纯阳 | 阳、火 | 朝阳采气，修行同时温养气血 |

灵根与流派契合时，静室修炼额外获得 **4 修为**，流派专属行动额外获得 **6 修为**，破境成功率提高 **4 个百分点**，总概率仍以 95% 为上限。这些收益与灵根、流派、命格、装备和道侣的收益叠加，行动卡显示合计效果。

全部 100 种组合都可以游玩。未契合不会扣减属性，仍保留自身加成和流派专属行动。创建界面给出推荐关系与组合预览，人物卡可随时查阅。每个流派还有一场独有奇遇，能带来物品或长期传承。

通用的「练习御剑」仍只要求持有青锋法剑，任何流派都可使用。旧存档保留原来的灵根、流派与数值，自动获得对应专属行动和契合效果，不重新发放初始属性。

**飞升是新阶段的开始。** 真仙仍有寿元上限，仙界会开放更高阶的同道、秘境、拍品与对手。只有仙帝境完成这一卷修行。

寿元由当前境界决定，剩余寿元等于上限减去年龄。突破只提高上限，不会重置年龄；失败不会延寿。年末奇遇处理完毕后长一岁，达到当前上限时寿终，因此在最后一个可行动年份突破，仍能延续仙途。游戏没有固定六十年期限。

连续因缘按当前寿元检查是否还有足够时间兑现；突破后可接取此前来不及完成的因缘。已经接下的故事仍遵守原约定期限。

## 能力、成长与概率

| 项目 | 用途 |
| --- | --- |
| 修为 | 达到门槛后可破境，成功时扣除门槛，多余修为保留 |
| 悟性 | 提高破境概率和参悟类奇遇成功率 |
| 体魄、神识 | 提高战力，并参与相关奇遇检定 |
| 心境 | 提高破境概率，低于 20 时不能破境 |
| 气血 | 生存资源，低于 20 时不能破境；归零立即结束本局 |
| 寿元 | 当前境界允许的年龄上限，突破成功延长 |
| 声望 | 小幅提高战力；与善恶评价分别记录 |
| 灵石 | 坊市购买、炼制、拍卖、秘境入场与部分事件支出 |
| 宗门贡献 | 山门差事获得，用于讲经及堂口兑换 |
| 善恶值 | 范围为 -100 至 100，影响坊市价格、部分奇遇、同道相处与宗门接纳 |

破境概率为 `38% + 悟性 × 0.3% + 心境 × 0.2% + 各项破境加成`，限制在 20%–95%。当年先前行动可能改变真正破境时的状态；界面展示当前预计概率。失败损失当前门槛 20% 的修为、10 气血与 8 心境，可以休整后再试。

战力综合境界、体魄、神识、声望及装备、符箓、长期收获、道侣收益。普通奇遇检定概率为 `55% + (检定属性 - 难度) × 0.8%`，限制在 10%–95%；使用选择前的属性，不能靠同一选项的奖励提高当次概率。对战和秘境有各自的胜率规则，直接显示在相应面板。

境界提升后，普通行动的基础收益也提高。以炼气为第 0 境，正向基础修为乘以 `1 + 境界序号 × 0.3 + max(0, 境界序号 - 6) × 0.7`；正向基础灵石和贡献乘以 `1 + 境界序号 × 0.5`，并四舍五入。初始属性、灵根、命格、装备、契合等额外加成仍按固定数值叠加，费用和气血消耗不会随这个公式放大。

行动或天地游历中气血耗尽，会立即收卷；不能依靠排在后面的休整自动复活。一般年度结算会恢复少量气血和心境，但这也不会救回已经倒下的角色。

## 善恶与负面奇遇

| 善恶值 | 外界评价 | 实际影响 |
| --- | --- | --- |
| 60 至 100 | 功德真人 | 坊市基础价减 5%，满足部分正道同伴和奇遇的要求 |
| 20 至 59 | 侠义之名 | 坊市基础价减 5%，开启相应善名奇遇 |
| -19 至 19 | 未有定评 | 坊市按通常价格交易 |
| -59 至 -20 | 行事乖张 | 坊市基础价加 15%，部分同道不愿相处，可能引来旧怨 |
| -100 至 -60 | 恶名昭著 | 坊市加 15%，宗门拒绝新入门和堂口兑换，可继续行善挽回 |

善恶价格修正与丹霞谷的 10% 宗门折扣相加：例如有善名的丹霞谷弟子按基础价的 85% 购买，恶名时按 105% 购买，结果向上取整。该修正用于普通坊市，不改拍卖报价或堂口贡献费用。

切磋、助人和赈济可以改善评价；抢劫等行为会降低评价。所有流派都能安排「赈济乡里」，花 60 灵石换取善恶值 +8、声望 +2、心境 +2。已有宗门不会因为恶名自动消失，但其堂口会暂停接待，直到评价改善。

64 个奇遇中含 **14 个负面事件**，覆盖瘴气、火灾、走火入魔、旧怨、善名带来的求助负担、仙界乱流等。负面事件也可能与善恶、境界及现有属性有关。道具能帮助应对某些风险，但无资源时的退路也可能受伤、损失修为，低气血时尤其需要谨慎。

## 坊市、炼制与连续因缘

共有 31 项行动（含 10 项流派专属修行）、18 件物品、3 种临时增益、64 个奇遇（含 10 个流派专属奇遇）与 3 条连续因缘。5 件拍卖珍品不在普通坊市出售。

坊市买卖只使用游戏中的灵石。装备持有即生效；丹药、符箓与灵茶在行囊中使用，材料用于炼制或相关奇遇。购买和服用物品不占修行或天地游历次数，炼丹、锻器仍占修行格。年度安排逐项预留灵石、贡献与材料，不能把同一份资源重复花费。

- 小周天注疏提高静坐效率；青锋法剑提高战力并开启御剑练习；踏云履、清心竹笛与玄铁护臂改变相应行动收益。
- 「采药 → 炼丹 → 服用聚气丹」用于积累修为；「采矿 → 锻器 → 使用护身符」用于准备险地探索。丹修与阵修有自己的材料转化方法。
- 破境丹、护身符与灵茶状态持续 3 个年份，每次年末奇遇处理后扣一年；天地游历与读档不会单独扣时长。同类增益不能叠加使用。
- 经脉受伤会锁定山海游历、瀑下炼体、熬骨淬身和引雷淬脉。归舍休整、续脉膏或涅槃仙露可以解除伤势；仅恢复气血不会自动解除。
- **一程风雪**：3 年内护送商队两次，交付后取得尾款与商路故交。
- **无名洞府**：4 年内完成三次秘境考据，获得古阵传承。这里的故事考据与下文的三关秘境分别记录。
- **山雨里的小兽**：3 年内照料幼兽两次，可留下长期灵兽伙伴；灵兽伙伴与成年道侣是不同的系统。

因缘目标达成或截止时，后续优先出现；多个后续按截止年份排序。按时完成的进度可以等待结算，过期后不能继续推进。每段因缘只体验一次，奖励不会重复发放；未完成故事也会留下记录。

## 天地游历：每年两次

天地游历与三格修行分别计数，以下活动每次消耗 1 次游历：同道闲谈、赠礼、结契或告别，参与一次拍卖报价，进入秘境，探索一关，以及进行一场对战。年末处理奇遇、进入新一年后恢复为 2 次，不能无限点击刷取收益。

进行天地活动或堂口兑换前，需要先清空当年的修行安排；可以先办完这些事，再排三件修行。堂口兑换不耗游历次数，退出秘境也不耗次数。正在探索的秘境、同道关系和历史记录会跨年保留。

### 宗门设施

拜入宗门后可使用炼丹堂、藏经阁和炼器堂，共有 10 项贡献兑换。

| 设施 | 兑换内容 |
| --- | --- |
| 炼丹堂 | 聚气丹 ×2 / 30 贡献；续脉膏 ×2 / 20；破境丹 ×1 / 40；赤玉灵果 ×2 / 25 |
| 藏经阁 | 吐纳真解 / 100 贡献；经义辨微 / 80；真仙境的太清仙经 / 400 |
| 炼器堂 | 青锋法剑 / 80 贡献；踏云履 / 50；元婴境的玄铁护臂 / 180 |

书籍传承会永久改变相关行动收益或破境概率。已掌握的传承、已持有的同件装备不能重复兑换，消耗品仍受背囊上限约束。讲经另需每次 10 贡献与 30 灵石，可用差事积累的贡献稳定提升修为、悟性。

### 同道与道侣

六位可相识的同道均为成年人，各有流派、性格、境界要求、善恶要求和结契后的实际加成。闲谈增加 12 相知；赠礼花 60 灵石，增加 20 相知，上限为 100。同一位同道每年最多闲谈或赠礼一次。

玩家年满 **18 岁**、相知达到 **60**，并满足对方的境界和善恶要求后，才可主动提出同行之约，由双方明确同意后结为道侣。不会自动结婚，同时只能有一位道侣；可以平静告别，过去的相识记录仍会保留。结契和告别也各占一次游历，当年不能反复重新结契。

结契解锁「同心共修」并提供该同道的常驻收益，具体效果会显示。道侣不是可消耗的物品。抢劫无论成败，都会让部分重视善行的道侣相知降低 25；降至 0 时对方会主动断缘，共修和加成随之结束。

### 拍卖场

每年随机生成 3 件拍品，目录随境界扩展。炼气阶段也能参加；金丹后开始出现周天星图，之后还有雷纹镇心玉、太虚清音钟、镇星古印与涅槃仙露。

采用一次性的密封报价：显示底价、数量与竞争者报价范围，不提前公开对方的确切报价。每件拍品每年只能报一次整数灵石；高于竞争者才胜出，同价由对方成交。赢者按自己的报价付款，未赢者不扣灵石，但两者都消耗一次游历。自己的报价不能超过现有灵石，背囊也必须放得下拍品。

拍品和对手报价随当年存档保存，重新打开网页不会重抽。下一年才刷新新拍品。所有交易使用虚拟灵石，不涉及真实付款。

### 三关秘境

| 秘境 | 最低境界 | 入场灵石 | 最终所得 |
| --- | --- | ---: | --- |
| 雾隐峡 | 炼气 | 60 | 灵石、修为、药草与聚气丹 |
| 沉璧水府 | 金丹 | 220 | 灵石、修为、破境丹与潮生道痕 |
| 万雷古府 | 大乘 | 600 | 灵石、修为、护身符与雷府古篆 |
| 星海残墟 | 真仙 | 1,200 | 灵石、修为、仙露与星墟道标 |
| 古帝传道陵 | 金仙 | 3,000 | 灵石、修为、仙露与古帝传道 |

每处秘境有 3 关。进入消耗一次游历及入场费，每探索一关再消耗一次游历，因此通常需要跨年完成。每关都可选择谨慎探查或冒险深入：谨慎胜率较高、伤害较低；冒险每关成功时获得更多修为，但伤害更大，失败还会受伤。胜率、具体损失和最终奖励会在探索前显示。

成功也可能损失气血，气血不足时甚至无法活着带回奖励。失败会撤出秘境，次年才可重试；主动离开不受伤、不耗游历次数，但不退入场费，下次从第一关重新开始。第三关奖励放不进背囊时会暂停探索，并提示整理行囊或安全离开。

每处秘境一生只能完成并领取传承一次，成功、失败及主动退出的记录可查。秘境不会自动随年末消失。

### 切磋与抢劫

四位对手均为虚构成年修士，按境界逐渐开放。面板展示双方战力、胜率、所得、气血风险和善恶变化。同一对手的同一种对战，每年最多一次，仍受总计两次游历限制。

- **切磋**：无论胜败善恶 +2，胜者修为收益更高，败者也有少量心得。气血最多降至 1，不会因切磋本身陨落。
- **抢劫**：无论胜败善恶 -18。获胜夺取灵石，成功也会损失气血；失败损失更多气血并受伤，可能直接陨落。正派道侣也可能因这种选择疏远你。

## 存档与隐私

每次操作自动保存到当前浏览器，支持导出、导入 JSON 行卷。换设备、换浏览器、清理网站数据，或从本机转到线上网址前，请先导出行卷。不同网址的存档相互独立。

随机种子、拍卖报价、同道关系、秘境进度和年度次数都随存档保存。导入会校验版本、数值、物品、关系及历史记录，不执行存档中的代码。网页不加载外部字体、统计或广告。

旧版 v1、v2 行卷升级为 v3 时：

- 普通中途存档保留年龄、原有数值、灵根流派、背囊和因缘进度，不重新发放初始属性或既得奖励。
- 旧版飞升记录接续为新版的 **真仙**。如果角色仍存活，原飞升结局会恢复为可继续修行的状态，年龄保持不变；之后可沿仙界境界继续前行。
- v1 因原六十年限制而结束、气血仍大于 0 且尚未飞升的角色，会在 76 岁继续仙途。
- 已经陨落的角色保持死亡结局。此前已完成或已结束的因缘保留，不重新开放领取奖励。
- 新增善恶值从 0 开始，天地游历记录按迁移后的年份初始化；原有长期灵兽伙伴与新同道关系分开保存。
