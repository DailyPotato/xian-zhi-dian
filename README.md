# 仙之巅

**破境延寿，自成一道。** 原创中文修仙文字养成游戏，从十六岁初入山海直到飞升仙界、登临仙帝。

- 游戏：https://dailypotato.github.io/xian-zhi-dian/
- 仓库：https://github.com/DailyPotato/xian-zhi-dian

当前版本 **v3.0.0**，存档版本 **4**。原生 HTML / CSS / JavaScript，无构建步骤、后端、第三方运行依赖或 API 密钥。

## 开局随机测灵

新人生自动测得灵根资质与属性，不再手动选灵根。同一种子给出相同结果；重新抽取命格不会改变本次测灵。10 条修行流派仍可自由选择，36 项命格抽 8 选 2、可重抽两次。

| 灵根资质 | 概率 | 属性数 | 正向行动修为倍率 | 破境修正 |
| --- | ---: | --- | ---: | ---: |
| 天灵根 | 8% | 1 | 1.4 | 6 个百分点 |
| 变异灵根 | 12% | 1 | 1.25 | 4 个百分点 |
| 双灵根 | 25% | 2 | 1.1 | 2 个百分点 |
| 三灵根 | 30% | 3 | 1 | 0 个百分点 |
| 杂灵根 | 25% | 4–5 | 0.8 | -3 个百分点 |

天灵根、双灵根、三灵根、杂灵根从金木水火土中抽取不重复属性；变异灵根从冰雷风阴阳中抽取。主灵根提供原有初始属性与行动加成；包含任一契合属性即可获得流派契合。静室修炼契合 +4 修为、流派专修 +6 修为、破境概率 +4 个百分点；各项正向行动修为合计后再乘资质倍率。杂灵根进境较慢，也可依靠流派、功法、丹药和宗门修至高境界。

## 岁月按行动推进

取消年度三格计划和天地游历两次配额。每次直接执行一件事，先查看收益、风险与耗时，再决定是否付出这段寿元。

- 月是时间的最小单位：采药、营生、休整通常 1 个月；炼气静修 3 个月、破境 6 个月。
- 带境界耗时的修炼，按境界依次乘 1、1、2、3、4、6、8、12、18、24、36、60、100、100；生活和连续故事任务用固定月数。
- 交谈、赠礼、结契、拍卖、切磋、抢劫、入宗、晋升各耗 1 个月。秘境入境 1 个月、谨慎探关 3 个月、冒险探关 2 个月。
- 坊市购买、使用丹药、贡献兑换、离开秘境及回应已出现的奇遇不额外推进时间。
- 每次行动直接增长年龄并消耗剩余寿元，不降低境界的寿元上限。行动必须在寿元耗尽之前完成，不能靠临终前无法完成的突破延寿。
- 不再自动每年恢复气血；需要休整、丹药或相应行动调养。气血归零结束此生。
- 一般修行后有 30% 概率遇见奇遇，游历类为 55%；已完成或到期的连续故事优先带来后续。回应奇遇不重复扣时间。
- 丹药增益按实际经过月数衰减。行动开始时仍有效的增益参与本次结算，结束时扣除整个行动经过的时间。

日期显示为修行第几年几月，年龄和剩余寿元精确到月。拍卖、同道相处、同类对战的年度刷新仍以真正跨过日历年为准，没有额外的年度结算按钮。

炼丹堂、藏经阁、炼器堂合计 10 项兑换。丹药、装备与长期功法要求相应境界和职务；太清仙经还要求加入仙界宗门。已学永久功法不能重复兑换。恶名达到 -60 时暂停入门、晋升和堂口接待，行善可恢复资格。

## 天地游历与因果

- **道侣**：6 位成年同道，交谈和赠礼增进好感。角色满 18 岁、相知达到 60 且满足善恶要求后可自愿结契，仅能同时拥有一位。解锁同心共修和常驻收益，也可分别。劫掠会让重视善行的道侣降低 25 好感，归零则断缘。
- **拍卖**：每个日历年 3 件密封竞拍，含 5 件专属珍物。显示起拍价及对手报价范围；严格高于对手才胜出，平价对手胜。赢家支付自己的报价、败者不扣灵石，双方均耗时。每件只可报价一次。
- **秘境**：雾隐峡、沉璧水府、万雷古府、星海残墟、古帝传道陵，逐境开放。各有三关、明确成功率、气血风险和真实奖励。进度跨年保存，通关此生仅一次，失败次年可重试，随时免费撤退。
- **对战**：4 位对手。切磋点到为止，最低剩 1 气血，无论胜负善恶 +2；抢劫无论胜负善恶 -18，胜出夺灵石，失手可能重伤或陨落。同一对手同一种模式每个日历年一次。
- **奇遇**：64 场，其中 14 场负面事件，结合属性、境界、善恶与流派抽取。没有资源时仍有选项，但不保证无伤。3 条连续因缘有精确月数期限和永久回报。

善恶为 -100 至 100：60 起功德真人，20 起侠义之名，-19 至 19 未有定评，-20 起行事乖张，-60 起恶名昭著。善名坊市减价 5%，恶名加价 15%，与宗门折扣相加；同时影响同道、事件和宗门待遇。赈济乡里可改善评价。

## 存档与兼容

每次操作自动保存到当前浏览器，可导出、导入 JSON。不同网址的存档相互独立，换设备或清理数据前请先导出。无外部字体、广告、统计和进度上传。

v1–v3 存档自动迁移至 v4：

- 保留原灵根、流派、年龄、资源、道侣、秘境与既有功法。旧灵根标为“原有灵根”，保持原有收益，不强制重抽资质。
- 未执行的三格计划解除，不消耗资源；待答奇遇保留。旧丹药剩余年数转为月数，旧故事保留整个原截止年份的可行动时间。
- 原宗门保留，从外门职务衔接，当前贡献记入初始累计功绩；之后新获得的贡献继续累计。
- 健康的旧飞升结局接续为真仙；v1因旧六十年期限而结束的健康角色从76岁继续。死亡存档仍保留死亡结局。
- 随机种子和隐蔽报价保存，加载不重抽奖励。导入会验证各项数值、资质、日期、职务和历史记录，失败操作不扣资源或改变随机序列。
