# 仙之巅

**破境延寿，自成一道。** 一款原创中文修仙文字养成游戏。从十六岁入山，到叩问天门，灵根、命格、道途和每一年的选择，共同写成这一生的行卷。

- 游戏：https://dailypotato.github.io/xian-zhi-dian/
- 仓库：https://github.com/DailyPotato/xian-zhi-dian

原生 HTML / CSS / JavaScript，无构建步骤、无第三方运行依赖、无后端或 API 密钥。可在 GitHub Pages 或本机运行，存档仅留在玩家浏览器。

## 怎么玩

1. 选择姓名、10 种灵根与 10 条道途；契合搭配能提高修炼和破境收益，各流派拥有专属行动与奇遇。36 项命格随机抽出 8 项，从中选择 2 项，可重新抽取两次。
2. 每年安排 3 件事，再推进这一年。静室修炼积累修为，参悟提高悟性，炼体和凝神提高战力，休整恢复气血与心境。
3. 修为达到境界门槛，且气血、心境都不少于 20，可以安排一次闭关破境。每年最多尝试一次，破境占用一个行动格。
4. 年末处理奇遇。检定选项会显示概率与成败后果，也始终保留无需支出或门槛的安全选择。
5. 筑基后可拜入云岚剑宗、丹霞谷或听雨阁，也可终生不入宗门。师承一经选定，本局不再改投。
6. 逐步经历炼气、筑基、金丹、元婴、化神与飞升，成功突破会提高寿元上限。每次年末奇遇处理完毕后长一岁，达到当前境界的寿元上限时收卷；飞升则超脱寿元，直接进入飞升结局。气血归零会提前结束，行动中倒下不会被稍后的休息自动救回。

## 灵根与流派

灵根包括金、木、水、火、土、冰、雷、风、阴、阳，每种都有不同的初始属性和行动收益。流派与宗门相互独立，选择流派后仍可拜入任一宗门。

| 流派 | 契合灵根 | 修行侧重 |
| --- | --- | --- |
| 剑修 | 金、风 | 剑意与体魄 |
| 丹修 | 木、火 | 炼丹与灵材转化 |
| 逍遥 | 水、风 | 游历见闻与灵石 |
| 体修 | 土、阳 | 强健筋骨 |
| 阵修 | 土、水 | 布阵与炼制护符 |
| 御兽 | 木、阳 | 神识与灵兽沟通 |
| 玄冰 | 冰、水 | 吐纳与凝神 |
| 雷修 | 雷、金 | 引雷淬体 |
| 魂修 | 阴、冰 | 识海与心神 |
| 纯阳 | 阳、火 | 阳气与周天 |

灵根与流派契合时，静室修炼额外获得 **4 修为**，流派专属行动额外获得 **6 修为**，破境成功率提高 **4 个百分点**（总概率仍以 95% 为上限）。这些收益与灵根、流派、天赋和装备的原有收益叠加，行动卡直接显示合计效果。

全部 100 种组合都可以游玩。未契合不会扣减属性，仍保留自身加成和流派专属行动。创建界面给出推荐关系与组合预览，人物卡可随时查阅；其他流派的专属行动不会混入年度安排。每个流派还有一场独有奇遇，能带来物品、临时效果或长期传承。

旧存档保留原来的灵根、流派与数值，并自动获得相应专属行动和契合效果；不会重新发放初始属性。新灵根、流派只需在重开时选择。

## 破境与寿元

| 境界 | 寿元上限 | 成功晋入时的延寿 |
| --- | --- | --- |
| 炼气 | 100 岁 | 初始寿元 |
| 筑基 | 200 岁 | +100 年 |
| 金丹 | 500 岁 | +300 年 |
| 元婴 | 1,000 岁 | +500 年 |
| 化神 | 2,000 岁 | +1,000 年 |
| 飞升 | 无尽 | 不再受寿元限制，进入飞升结局 |

寿元由当前境界决定，剩余寿元等于寿元上限减去年龄。突破只提高上限，不会重置年龄；失败不会延寿。人物卡显示当前年龄、上限与余年，剩余 10 年以内会提示尽早破境。年末达到上限才会寿终，因此在最后一个可行动年份成功突破，仍能延续仙途。

游戏不再固定六十年结束。连续因缘也按当前寿元检查是否还有足够时间兑现，突破后可继续接取此前来不及完成的因缘；已经接下的因缘仍遵守原约定期限。

## 能力与进度

| 项目 | 用途 |
| --- | --- |
| 修为 | 破境消耗，当前门槛依次为 90 / 180 / 280 / 420 / 560；多余修为保留 |
| 悟性 | 提高破境概率和参悟类奇遇的成功率 |
| 体魄、神识 | 提高战力，并参与各自相关的奇遇检定 |
| 心境 | 提高破境概率，低于 20 时不能破境 |
| 气血 | 生存资源，低于 20 时不能破境；归零结束本局 |
| 寿元 | 当前境界允许的年龄上限；突破成功延长，岁末达到上限时收卷 |
| 声望 | 小幅提高战力，也参与人情类奇遇 |
| 灵石 | 买丹药、法宝与材料，支付部分修行费用 |
| 宗门贡献 | 山门差事获得，可听长老讲经，也可在宗门奇遇里兑换物资 |

破境概率为 `38% + 悟性 × 0.3% + 心境 × 0.2% + 灵根契合/命格/山门/因缘/丹药加成`，最终限制在 20%–95%。界面按当前状态显示预计概率；当年先前行动仍可能改变实际突破时的状态。突破失败损失当前门槛的 20% 修为、10 气血与 8 心境，仍可恢复后继续尝试。

战力由境界、体魄、神识、声望及装备、符箓、因缘共同决定。普通奇遇检定概率为 `55% + (检定属性 - 难度) × 0.8%`，限制在 10%–95%。检定使用选择前的属性，不能靠该选项自己的奖励提高当次概率。

## 坊市、炼制与因缘

共有 29 项行动（含 10 项流派专属修行）、12 件物品、3 种临时增益、50 个奇遇（含 10 个流派专属奇遇）与 3 条连续因缘。

坊市买卖只使用游戏里的灵石。装备持有即生效；丹药、符箓和灵茶需要在行囊使用，材料只能用于炼制或相关奇遇。买物品不占年度行动，炼丹、锻器仍占一格。年度安排会逐项预留灵石、贡献和材料，不能把同一份资源花两次。

- **小周天注疏**提高修炼效率；**青锋法剑**提高战力并开启御剑练习；**踏云履**和**清心竹笛**改变相应行动收益。
- **采药 → 炼丹 → 服用聚气丹**是一条可实际运转的修炼路径；**采矿 → 锻器 → 使用护身符**用于准备险地奇遇。
- 破境丹、护身符与灵茶的状态持续 3 个完整年份，每次年末奇遇处理后才扣一年，读取存档不会扣时长。同类增益不能叠加使用。
- **经脉受伤**会暂时锁定游历与炼体，归舍休整或使用续脉膏可恢复。
- **一程风雪**：3 年内护送商队两次，交付后获得尾款与商路故交。
- **无名洞府**：4 年内完成三次秘境考据，得到古阵传承。
- **山雨里的小兽**：3 年内照料幼兽两次，可留下长期灵兽伙伴。

因缘目标达成或截止时，专属后续优先出现；多个后续按截止年份顺序处理。按时完成的进度可以等待结算，过期后不能继续推进。每段因缘只体验一次，奖励不会重复领取；未完成的故事也会留下记录。

## 存档与隐私

每次操作自动保存到当前浏览器，支持导出、导入 JSON 行卷。换设备、换浏览器、清理网站数据，或从本机转到线上网址前，请先导出行卷。不同网址的存档相互独立。

随机种子随存档保存，同一进度重读仍保留之后的随机序列。导入会校验版本、数值、物品和因缘记录，不执行存档中的代码。网页不加载外部字体、统计或广告。

旧版行卷自动升级为寿元规则。中途存档保留现有年龄与进度；旧版因六十年限制而收卷、尚未飞升且气血仍大于零的角色，会在 76 岁继续修行。原有物品、伙伴与已完成或结束的因缘记录保留，奖励不会重发。已经陨落或飞升的角色维持结局。

## 本地运行与验证

直接打开 `index.html`，或安装 Node.js 后运行：

```text
node server.cjs
```

访问 `http://127.0.0.1:4174/xian-zhi-dian/`。

```text
node --test tests/engine.test.cjs
node --check app.js
```

测试包含 100 种灵根与流派组合、契合加成、专属行动与奇遇的归属检查、材料预算，以及完整寿元模拟、正常资源条件下飞升、各境界延寿与寿终边界、旧档迁移、突破成功失败、资源预留、临时增益时序、三段因缘、存档校验和失败操作不改变游戏状态。

本作的人物、宗门、奇遇和规则均为原创游戏内容。修炼、丹药与法术是虚构设定。
